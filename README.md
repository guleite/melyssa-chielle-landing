# Melyssa Chielle — Landing page

Landing page de apresentação para **Melyssa Chielle Arquitetura & Interiores**.

## Conteúdo
- `index.html` — página completa (HTML, CSS e JS em um único arquivo).
- `img/` — fotos dos projetos e retrato da arquiteta (fonte: site melyssachielle.com.br).

## Como visualizar
Abra o `index.html` no navegador. As fontes vêm do Google Fonts e a rolagem suave usa a biblioteca Lenis (via jsDelivr), então é preciso estar conectado à internet.

## Observações
- Depoimentos e os números "12 anos" e "+85 mil m²" são provisórios e devem ser substituídos por dados reais.
- O formulário de qualificação monta a mensagem e direciona para o WhatsApp do escritório; ele não grava dados em servidor.
